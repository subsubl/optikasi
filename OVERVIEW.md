# optikasi-blog-hub-v2 — Overview

Three new blog articles created in the Nuxt 4 application following the established template pattern. Each article implements the existing useArticleSchema composable for SEO optimization, includes proper semantic HTML structure with h1, h2 headings and ul lists, features a back navigation link, hero image, and final CTA to /kontakt page. Content focuses on clinical/optometry topics: contact lenses, progressive lenses, and lens coatings.
